# Review build readiness

Review the accepted specification, implementation plan, task DAG, generated contract
scopes, decision authority, and verification obligations as one handoff boundary.
Challenge stale or incomplete scope and identify exact blocked Tasks or governing
entities.

Return a readiness review. Do not generate Build Contracts, calculate readiness
independently, or persist the Build Contract gate; those remain deterministic or
human-owned Lengthwise decisions.
