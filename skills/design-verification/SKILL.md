# Design verification

Define verification methods that directly observe the accepted criteria. State
applicability and complementary Evidence kinds where one result cannot support the
judgment alone. Prefer the smallest sufficient topology, not a target count or an
automation preference.

Return Verification-definition changes only. Never fabricate an observed result or
Evidence; unavailable execution remains an explicit future verification obligation.
