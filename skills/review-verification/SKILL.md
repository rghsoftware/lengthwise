# Review verification

Review current required Verification definitions and their linked Evidence. Assess
provenance, context or revision applicability, outcomes, and complementary Evidence
requirements. A missing, stale, inapplicable, or inconclusive result remains a
blocker; it is neither success nor automatically an implementation defect.

Return a verification review with exact Verification and Evidence references. Do
not privilege automation, duplicate a credible result for metrics, fabricate
Evidence, or persist the final human gate.
