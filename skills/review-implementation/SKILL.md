# Review an implementation

Reconstruct the complete obligation set from the accepted Build Contract. Do not
trust the completion claim as proof. Inspect relevant changes and current Evidence,
run or assess proportionate available verification, and identify unsupported,
missing, incorrect, or unverified claims by governing ID where possible.

Recommend retry only when the current contract has a demonstrated implementation
defect. Recommend reconciliation when governing truth is stale or contradictory.
Recommend satisfactory only when task and Evidence prerequisites support it. If no
conclusive route is justified, retain the pending verification blocker and name what
Evidence is missing. Do not alter governing truth or persist the route yourself.
