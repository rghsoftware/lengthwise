# Plan a feature

Decompose the accepted specification into cohesive Tasks with explicit dependency
order and implementation traceability. Record material technical Decisions at the
authority supplied; leave harmless local choices delegated. Ensure the plan covers
the whole Feature and coordinates its verification topology.

Return plan and task changes. Do not generate Build Contracts: Lengthwise derives
those deterministically from accepted governing context.
