# Reconcile a feature

Compare current governing artifacts, accepted contracts, implementation discoveries,
Evidence, and deterministic findings. Distinguish stale derived boundaries from a
genuine change to product or technical truth. Propose the smallest coherent set of
artifact changes and the workflow route required to converge.

Preserve accepted authority. Do not silently rewrite LOCKED Decisions or material
behavior to make implementation pass. Name the affected entities, invalidated
contracts or Evidence, and the human authority required for any material change.
